    Rentui.kg - Доска объявлений для аренды жилья

Rentui.kg - Это веб-сервис для поиска и размещения объявлений об аренде жилья в Кыргызстане.  
Проект помогает пользователям быстро находить жильё по выгодным условиям напрямую от арендодателей.


    🚀 Функционал

На текущий момент реализовано:

- Регистрация пользователей  
- Авторизация  
- Создание объявлений (только для зарегистрированных пользователей)  
- Просмотр объявлений  
- Веб-интерфейс  
- Адаптивная верстка (ПК, смартфоны, планшеты)

    🛠 Используемые технологии

 ⚙️ Установка и запуск локально

1. Клонировать репозиторий:
   git clone https://github.com/a1tvv/rentui.kg.git
   cd rentui.kg

2. Создать и активировать виртуальное окружение:
    python -m venv venv
    source venv/bin/activate  # Linux / Mac
    venv\Scripts\activate     # Windows

3. Установить зависимости:
    pip install -r requirements.txt

4. Выполнить миграции:
    python manage.py migrate

5. Запустить сервер:
    python manage.py runserver

    🧩 Архитектура проекта

Проект построен по классической MVC-архитектуре Django:

- models.py - модели данных
- views.py - бизнес-логика
- templates/ - HTML-шаблоны
- static/ - стили и статические файлы
- urls.py - маршрутизация
